# Cifereca Diagnostics Preflight 0.1.0

Plugin autonome de prédiagnostic compatible avec le Core initial `0.9.44+dev.1`.

Installation :

```sh
cifereca-cli plugin install cifereca-plugin-diagnostics-preflight-0.1.0.zip
```

Puis ouvrir **Prédiagnostic** dans Cifereca et utiliser **Copier**.

Le plugin travaille en lecture seule. Il n'exporte pas les valeurs de configuration, credentials, tokens, cookies ou secrets.
